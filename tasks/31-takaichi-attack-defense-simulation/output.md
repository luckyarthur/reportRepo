## 二、制度基础：两条不同的赛道

**日本没有「总统」。**「把高市早苗拉下台」在制度上是**两件不同的事**，混淆二者是理解日本政局最常见的错误。

| | **国家赛道** | **政党赛道** |
|---|---|---|
| 职位 | 内阁总理大臣（内閣総理大臣・首相） | 自民党总裁（自由民主党総裁） |
| 产生方式 | 国会指名（**宪法第67条**），众议院决议优先 | 党内程序（党则） |
| 免职机制 | 内阁不信任决议（**宪法第69条**）、内阁总辞职、首相辞职 | 总裁选举、总裁选提前实施（**党则第6条4项**）、辞任 |
| 外部可否发动 | 可以——在野党可提出不信任案 | **不可以**——只有自民党内部才能发动 |
| 实际效果 | 通过后首相须在10日内解散众议院**或**内阁总辞职 | 在自民党为执政第一大党的前提下，**失去总裁即失去首相** |

### 本推演中最关键的四条条文

- **宪法第67条**：内阁总理大臣由国会决议在国会议员中指名。两院意见不一致且两院协议会不成立，或参议院在10日内不指名时，**以众议院的决议为国会的决议**。
- **宪法第69条**：众议院通过不信任决议案（或否决信任决议案）时，内阁须在10日内解散众议院，否则总辞职。**注意：只有众议院能做，参议院不能。**
- **宪法第59条第2项**：参议院否决的法案，**众议院以出席议员三分之二以上再次可决时即成为法律**。
- **宪法第60条**：预算先议于众议院；参议院作出不同决议且两院协议会不成立，或参议院在**30日内**不作决议时，**以众议院的决议为国会的决议**。

**这四条决定了本次推演的全部结构。**为什么，见第四节的席位算术。

### 自民党党则第6条4项（攻方最重要的党内武器）

> 党所属国会议员与都道府县支部联合会代表各1人的**总数之过半数**提出要求时，可临时实施总裁选举。

2025年石破政权时期的实际运作：当时自民党所属国会议员295人 + 都道府县联47 = 342，**过半数为172**。程序上，国会议员须向总裁选举管理委员会提交**签名盖章的书面文件**，都道府县联须经机关决议后以代表者名义提交；选管汇总后**公布姓名**。（[日経](https://www.nikkei.com/article/DGXZQOUA049I50U5A900C2000000/)、[自民党公告](https://www.jimin.jp/news/information/211297.html)、[時事](https://www.jiji.com/jc/article?k=2025080800646&g=pol)，A/B）

**换算到当前格局**：417（党所属国会议员）+ 47（都道府县联）= **464**，**过半数 = 233**。

**「公布姓名」这一程序设计，是守方最有力的制度性防御**——它把匿名的不满转换成具名的背叛，对靠本次大胜当选的新人议员构成极强的抑制。

## 四、席位算术：本推演的全部结构

这一节是整份报告的核心。把数字摆出来，攻方的处境立刻清楚。

| 机制 | 所需条件 | 当前格局 | 结论 |
|---|---|---|---|
| **内阁不信任决议案**（宪法69条） | 众议院出席过半数 | 自民单独 316／465 | **算术上不可能**。在野党全体合计至多约113席（465−352），距过半数（233）差120席以上 |
| **众议院3分之2再可决**（宪法59条2项） | 出席议员2／3 | 465×2／3 = **310**；自民单独 **316** | **守方单独即可跨过**。参议院否决法案不构成终局障碍 |
| **预算成立**（宪法60条） | 众议院优越，参议院30日不议即成立 | 自民单独过半 | **参议院无法阻止预算成立**，至多拖延30天 |
| **首相指名**（宪法67条） | 众议院优越 | 自民单独过半 | 即使参议院指名他人，仍以众议院决议为准 |
| **参议院问责决议案** | 参议院过半数 | 执政联盟 120／248，**少5席** | **在野党有可能通过**——但**无法律拘束力** |
| **国会同意人事** | 两院一致 | 参议院少5席 | **攻方真正能卡住的地方** |
| **自民党总裁选提前**（党则6条4项） | 464人之过半数 = **233** | 其中316人是2月大胜的当选者 | 门槛极高，但**这是攻方唯一的真实路径** |

**由此得出本推演的基本判断（推演值）：**

> 在当前席位格局下，**国家赛道对攻方已经关闭**。内阁不信任决议案不是一张可以打的牌，而是一个只能用于宣示的姿态。攻方若要成功，**唯一的现实路径是党内赛道**——把内阁支持率的下滑转化为自民党内 233 人的具名倒戈。而参议院的 5 席之差，是攻方唯一能制造实质痛感的杠杆，其作用是**制造党内压力的燃料，而非直接推翻内阁**。

## 五、历史基准率：战后日本首相是怎么下台的

| 首相 | 下台时间 | 表面触发机制 | **实际起作用的因素** |
|---|---|---|---|
| 宫泽喜一 | 1993年6月 | **不信任案通过**（党内造反派同调） | 党内分裂（自民党分党），而非在野党票数 |
| 安倍晋三（第一次） | 2007年9月 | 辞任表明 | 参院选惨败 + 健康 + 党内支持流失 |
| 福田康夫 | 2008年9月 | 辞任表明 | 扭曲国会下的施政瘫痪 + 支持率低迷 |
| 麻生太郎 | 2009年9月 | 众院选败北 | 选举 |
| 鸠山由纪夫 | 2010年6月 | 辞任表明 | 普天间问题 + 政治资金问题 + 支持率崩落 |
| 菅直人 | 2011年8月 | 辞任（「退阵三条件」） | **党内**逼宫 + 在野党以法案为人质 |
| 野田佳彦 | 2012年12月 | 众院选败北 | 选举 |
| 安倍晋三（第二次） | 2020年8月 | 辞任表明 | 健康 |
| 菅义伟 | 2021年9月 | **不参选总裁选** | 支持率低迷 + 党内判断其无法带领胜选 |
| 岸田文雄 | 2024年8月 | **不参选总裁选** | 政治资金问题 + 支持率低迷 |
| 石破茂 | 2025年9月 | 辞任表明 | 参院选败北 + **总裁选前倒し要求的联署压力** |

**统计结论（这是校准全部概率估计的锚点）：**

- 战后首相因**众议院不信任决议案通过**而下台的案例，实质上**只有1993年宫泽内阁一例**，而且那一例的决定性因素是**自民党内的造反**，不是在野党的票数。
- 其余绝大多数案例，触发机制是**党内支持流失**，触发条件是**国政选举的败北或临近**。
- **2025年石破案例是本推演最直接的模板**：党则第6条4项的联署压力被实际当作倒阁工具使用，而首相在计票结果公布前即辞任——**这说明该机制的杀伤力在于「公布姓名」带来的政治现实，而非投票本身**。

**因此，攻方的最优策略在历史上是清楚的：不要指望不信任案，要制造「这个首相带不动下次选举」的党内共识。**问题在于——下次众院选在 2030 年 2 月，下次参院选在 2028 年 7 月。**攻方缺少一场迫在眉睫的选举。**这是攻方在本推演中最根本的困境。

## 六、双方阵营、目标与底线

### 攻方（进攻方）——一个利益并不一致的联合体

| 构成 | 真实目标 | 底线 | 与其他攻方的冲突 |
|---|---|---|---|
| **主要在野党（立宪民主党等）** | 政权交替 | 不愿在自民 316 席的格局下促成解散总选举 | 希望高市继续在位，以便积累不满到 2028 参院选 |
| **自民党内反主流派／反高市** | 换总裁，**保住自民党政权** | 绝不要解散总选举，绝不要政权交替 | 与在野党的目标**根本相反** |
| **联合伙伴内的离心势力（维新内部）** | 提高谈判价格 | 不愿退出联合政权失去影响力 | 退出即失去筹码 |
| **舆论与媒体的问责压力** | 问责本身 | — | 无组织性 |

**攻方最大的结构性弱点：其内部两股最有力量的力量，目标互相抵消。**在野党要的是政权交替，党内反主流派要的是保住政权换掉人。二者唯一能合作的动作，是**把支持率打下去**，此外几乎没有可协调的行动。

### 第 1 回合 · 攻方：参议院阁僚问责决议 + 审议阻滞

**行动名称：** 不打首相，打阁僚——以「辞任多米诺」启动。

- **时间线：** 2～3周。
- **成功条件：** 该阁僚辞任，并引发第二、第三名阁僚被追究。
- **风险与反噬：** 问责决议无拘束力，若内阁完全无视，攻方将暴露其工具的空洞性。
- **成功概率估计：** 决议通过 65%（推演值，取决于在野党协调）；迫使辞任 30%（推演值——历史上问责决议迫使阁僚辞任的案例存在，但在众议院压倒性多数的政权下效果显著下降）。

**守方应对：预防性切割 + 议事日程控制**

### 第 5 回合 · 攻方：发动总裁选前倒し联署（核心一击）

- **党规依据：** 自民党党则第6条4项——党所属国会议员与都道府县联代表各1人的总数之过半数要求时，临时实施总裁选举。程序：国会议员提交**签名盖章**文书至总裁选举管理委员会，都道府县联经机关决议后以代表者名义提交；选管汇总并**公布姓名**（[自民党](https://www.jimin.jp/news/information/211297.html)、[日経](https://www.nikkei.com/article/DGXZQOUA049I50U5A900C2000000/)、[時事](https://www.jiji.com/jc/article?k=2025080800646&g=pol)，A/B）。

### 第 8 回合 · 攻方：法律问责路径（**条件性路径——以下为假设，非事实主张**）

> **重要声明：截至本报告研究日期（2026-09-11），检索未发现任何针对高市早苗本人的、已立案或已被司法确认的违法事实。以下整段仅为制度机制的条件性说明，不构成任何指控，也不暗示存在此类事实。**

- **制度机制（真实存在）：** 政治资金规正法、公职选举法上的罚则；检察的立案裁量；**检察审查会制度**——即使检察不起诉，由随机选出的市民组成的检察审查会两次作出「起诉相当」议决时，可导致强制起诉。
- **条件句形式的推演：** **假若**存在并被证实涉及首相本人或其核心周边的重大政治资金违法事实并进入立案程序，则历史经验（鸠山、岸田两例）表明，其对党内支持的破坏力远超任何在野党的议会动作，第5回合的 233 人门槛将在数周内变得可及。
- **在无此前提的情况下：** 攻方在本路径上**无可执行的动作**。以未经证实的指控进行攻击属于本推演第一节禁止的行为，且在现实中反噬极大。
- **成功概率：** **不可估计**——完全取决于一个本推演不虚构、也无法预判的外生事实。

## 十、复盘分析

### 10.1 哪些机制真正有杀伤力，哪些只是姿态

| 机制 | 本推演中的实效 | 结论 |
|---|---|---|
| **总裁选前倒し（党则6条4项）** | 唯一可能奏效者 | **真武器**，但门槛随执政党席位规模同步上升 |
| 国会同意人事否决 | 有实质痛感 | 小武器，杀伤有限 |
| 阁僚问责决议 | 可迫使人事调整 | 半武器，可被守方以人事程序吸收 |
| 参议院审议阻滞 | 被59条2项抵消 | **在 2/3 格局下近乎无效** |
| 离间联合伙伴 | 无效 | 单独过半使该牌失效 |
| **内阁不信任决议** | **完全无效** | **纯姿态** |

### 10.2 决定胜负的结构性变量

按重要性排序，这是本推演最重要的结论：

1. **众议院的三分之二（310席）门槛是分水岭。** 跨过它，参议院的否决权就从「障碍」降级为「延迟」，倒阁方在国家赛道上的一切手段同时失效。自民党单独316席，跨过了这条线。
2. **距下次国政选举的时间。** 历史基准率显示，日本首相下台几乎总是「选举失败或选举临近」驱动的党内判断。众院选距今约41个月、参院选约22个月，**攻方缺少最关键的燃料**。
3. **党内议员的席位是否依赖现任首相。** 316名众议院议员中大量为2026年2月大胜的产物，倒戈的个人成本极高。
4. **「公布姓名」的程序设计。** 党则第6条4项要求具名并公布，这使得党内倒阁从匿名的情绪变成具名的赌注，极大提高了发动成本。
5. **支持率的绝对水平。** 46～50%（推演值）在日本政治中属于「下行但未崩盘」。历史上被迫下台的政权通常已跌至20～30%区间。

### 10.3 敏感性分析：什么条件下结果会反转

| 假设变更 | 对结果的影响 |
|---|---|
| **若自民党在众议院不足 310 席（无2/3）** | 参议院的否决成为实质障碍，第6回合逆转，施政瘫痪成真，党内「换人」压力大幅上升。**倒阁概率由 ≤10% 升至约 35%（推演值）** |
| **若自民党在众议院不足过半（少数执政）** | 不信任案成为真实威胁，在野党协调的首相指名成为可行路径。**倒阁概率升至 60% 以上（推演值）** |
| **若距参议院选举只剩3个月** | 党内「这个首相带不动选举」的判断有了检验时点，第5回合的233人门槛在支持率低于35%时变得可及。**倒阁概率升至约 45%（推演值）** |
| **若维新退出联合政权** | 在众议院单独316席的前提下，**影响甚微**——这正是本推演最反直觉的发现 |
| **若出现被证实并立案的重大违法事实** | 决定性。历史（鸠山、岸田）显示此类事实对党内支持的破坏力压倒一切议会手段 |
| **若支持率跌破 30% 并持续三个月以上** | 党内计算改变，233人门槛进入可及范围 |

**一句话总结：决定日本首相能否被拉下台的，不是在野党做了什么，而是执政党自己的席位数、下次选举的距离，以及党内议员对自己饭碗的计算。**

## 十一、现实对照

### 本推演中最脆弱的假设

1. **假设自民党内不发生分党。** 1993年宫泽内阁正是因党内分裂而倒台——这是唯一一次不信任案真正奏效的案例。若自民党发生实质性分党，全部席位算术需要重算。
2. **假设不出现外生冲击。** 重大灾害、安全保障危机、金融危机、健康问题——安倍两次辞任中有一次即因健康。这些无法推演。
3. **假设支持率不发生断崖式下跌。** 本推演设定其在46～50%区间缓慢下行。
4. **假设议员定数削减法案不被通过。** 若众议院定数真的削减一成（465→约419），2/3门槛降至约279，自民党的余裕反而**增加**——这是维新主张的一个未被广泛讨论的副作用。
